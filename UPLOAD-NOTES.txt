How the images work
- Cards, the hero and the story load images/thumbs/<name>.webp. If a thumb is missing, the page
  falls back to the original file named in PROJECTS, so nothing breaks.
- When you add a project, add its entry to PROJECTS in script.js as before. A thumb is optional:
  export the card image at about 1000px wide as images/thumbs/<same name as the thumbnail>.webp.
- Case study galleries still load the original full-size images.
- All paths are relative now, so the site also works on a custom domain.

Sharing one project
- Add #project=<id> to the address, e.g. https://patetefelix.github.io/portfolio/#project=tke

Font
- San Francisco is used on Apple devices through the system font stack. Inter loads as the
  fallback on Windows and Android. No SF font files are in the repo.
